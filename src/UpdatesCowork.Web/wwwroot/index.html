    学習モードの表示

    上から開始・初回受信順、縦レーンは実行場所、色は処理の種類です。モデル・安全性検査の呼び出しは呼び出し先の列に配置します。内部 MCP と C# は同じ Hosted Agent 内です。列が収まらない場合は図を横にスクロールできます。矢印は受信順であり、依存関係や並列実行を示しません。

    「実測」は Web または Agent 側で計測した開始・終了・所要時間です。計測元・親子関係・モデルごとのトークン数はノードを選択して確認できます。Web と Agent の収集状態は別々に表示し、異なる計測元の親子関係は推測しません。種別・実行場所・経路は構成情報で、実ホスト・リージョンは未計測です。

    実測したモデル呼び出し・内部処理・所要時間・親子関係は「グラフィカル学習モード」で確認できます。
